# Iyana M. Farrar — Portfolio Website

A responsive, accessible static portfolio for GitHub Pages, built with semantic HTML, CSS, and modular vanilla JavaScript. No build step or dependencies required.

## Publish

1. Extract this ZIP and upload **the contents of this folder** (not the enclosing folder) to the root of `iyanafarrar-wq/Iyana-Farrar-s-Portfolio` on GitHub.
2. In repository Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)`.
3. Website URL: https://iyanafarrar-wq.github.io/Iyana-Farrar-s-Portfolio/

## Features

- Responsive navigation and original, unaltered official headshot in hero.
- Interactive project filtering and accessible project case-study dialogs.
- Image lightbox for recognition graphic.
- Five project profiles and dedicated sections for About, Experience, Recognition, Farrar Capital Group, Contact.
- Original supplied University City proposal linked as a PDF, with joint creator credit.
- Deep links to projects using `?project=nest`, `?project=matching`, `?project=empowerher`, `?project=university`, `?project=fcg`.
- No analytics, backend, form data collection, or external JS libraries.

## Original imagery

Images in `assets/` were copied from supplied uploads or previously extracted supplied portrait PDFs. No generative replacement portraits or fabricated NEST/ITMP screenshots are included. CSS crops images visually for layout but never changes image file contents.
